## 메인 로고 가이드

- 추천 규격: 정사각형 비율(1:1)로 최소 600px 이상의 해상도를 권장합니다. 히어로 비주얼은 CSS에서 `clamp(240px, 32vw, 320px)` 폭으로 표시되므로, 2048px 정도까지 제작해 두면 고해상도 디스플레이에서도 선명하게 유지됩니다.
- 파일 포맷: 배경이 투명한 PNG 또는 WebP를 사용하면 유리판(glassmorphism) 배경과 자연스럽게 어울립니다. 벡터 기반이라면 SVG로 내보내는 것도 좋습니다.
- 안전 영역: 중앙 70% 영역 안에 주요 심볼을 배치하고, 가장자리는 약간 여백을 남겨 두면 반응형 축소 시에도 잘리지 않습니다.
- 색상 대비: 메인 배경이 짙은 네이비 계열이므로 밝은 톤 또는 그라데이션을 활용하면 시인성이 좋아집니다. 다크 테마에서의 발광 효과를 고려해 외곽에 살짝 글로우를 주면 잘 어울립니다.
- 교체 방법: `index.html`의 `<svg class="cat-illustration">` 블록을 `<img src="assets/images/teamhyeok-logo.png" alt="팀혁 로고" class="hero__logo">` 등으로 대체하고, 동일 경로에 로고 파일을 추가하면 즉시 반영됩니다.

## 팀 운영 원칙

1. teamHyeok은 우리가 만들고 싶은 걸 만듭니다.
2. 순수하게 개발자로만 구성되고 유지됩니다.
3. 구성원은 어떠한 경우에도 4인을 넘기지 않습니다.
4. 발생하는 수익은 공평히 분배됩니다.
5. 만들어진 개발물에 대해선 뒤돌아보지 않습니다.
6. 최저 비용, 구현 우선을 목표로 합니다.
7. 프로젝트 규모가 커질 경우 드랍하거나 타 개발자에 이전합니다.
8. 어떤 개발건이든, 개발 착수에서 완성까지 25일을 넘기지 않습니다.
9. 모든 구성원들은 동료를 존중하고 존경합니다.
